양방향 동기화

코드와 GUI가 실시간으로 동기화됩니다. 코드를 수정하면 다이어그램이, 마우스로 편집하면 코드가 자동 업데이트됩니다.

100% 브라우저

서버가 필요 없습니다. WebAssembly 기반으로 브라우저에서 모든 렌더링이 이루어집니다.

URL로 공유

다이어그램이 URL에 인코딩됩니다. 링크 하나만으로 누구에게나 공유할 수 있습니다.
