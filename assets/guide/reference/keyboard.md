# 단축키 & 마우스 인터랙션

## 키보드 단축키

| 동작 | 단축키 |
|------|--------|
| 코드 포맷 | `Shift+Alt+F` |
| 코드 패널 접기/펼기 | `Ctrl+\` / `Cmd+\` |
| 저장 차단 | `Cmd+S` / `Ctrl+S` (브라우저 저장 방지용으로 차단됨) |

> **참고**: grim은 URL에 자동 저장되므로 별도의 저장 단축키가 필요 없습니다.

---

## 미리보기 패널 단축키

| 동작 | 단축키 |
|------|--------|
| 화면 위로 스크롤 | `W` |
| 화면 아래로 스크롤 | `S` |
| 화면 왼쪽으로 스크롤 | `A` |
| 화면 오른쪽으로 스크롤 | `D` |
| 줌 인 / 줌 아웃 | `Ctrl + 마우스 휠` |

> WASD 스크롤은 코드 에디터 또는 입력 필드에 포커스가 없을 때만 동작합니다.

## 마우스 인터랙션

### 노드

| 동작 | 방법 |
|------|------|
| 노드 선택 | 노드 클릭 |
| 노드 이동 | 노드 드래그 |
| 노드 이동 (그리드 스냅 무시) | `Alt` + 노드 드래그 |
| 노드 크기 조절 | 노드 선택 후 테두리 핸들 드래그 |
| 크기 조절 (그리드 스냅 무시) | `Alt` + 테두리 핸들 드래그 |
| 코드 위치로 이동 | 노드 클릭 (에디터 커서가 해당 줄로 이동) |

### 엣지

| 동작 | 방법 |
|------|------|
| 엣지 선택 | 엣지 클릭 |
| 웨이포인트 추가 | `Alt` + 엣지 클릭 |
| 웨이포인트 제거 | `Alt` + 웨이포인트 클릭 |
| 웨이포인트 이동 | 웨이포인트 드래그 |
| 웨이포인트 이동 (그리드 스냅 무시) | `Alt` + 웨이포인트 드래그 |
| 코드 위치로 이동 | 엣지 클릭 (에디터 커서가 해당 줄로 이동) |

### 줌 버튼

| 버튼 | 동작 |
|------|------|
| `Code ▶` / `◀ Code` | 코드 패널 접기/펼기 |
| `−` | 줌 아웃 (10% 감소) |
| `+` | 줌 인 (10% 증가) |
| `Reset` | 100%로 초기화 |
| `Fit` | 다이어그램이 미리보기 영역에 맞게 조절 |

## 에디터 단축키

| 동작 | 단축키 |
|------|--------|
| 들여쓰기 | `Tab` |
| 내어쓰기 | `Shift+Tab` |

> 에디터는 탭 크기 4를 기본으로 사용합니다.

---

## 그리드 스냅

드래그할 때 노드와 웨이포인트는 **16px 그리드**에 스냅됩니다. 정밀한 위치 지정이 필요할 때는 드래그 중 `Alt` 키를 누르면 스냅이 해제됩니다.
