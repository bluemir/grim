# 빠른 시작

## grim이란?

grim은 "코드로 구조화하고, 마우스로 완성하는" 양방향 다이어그램 도구입니다.

- **Diagram-as-Code**: D2/Mermaid처럼 텍스트로 다이어그램 구조를 정의합니다.
- **양방향 동기화**: 마우스로 노드를 옮기거나 크기를 조절하면, 변경 사항이 코드에 자동으로 반영됩니다.
- **100% 브라우저**: Go 코어를 WebAssembly로 컴파일하여 서버 없이 동작합니다.

> 기존 Diagram-as-Code 툴은 오토 레이아웃의 한계로 세밀한 위치 조정이 어렵고, GUI 툴은 버전 관리(Git)가 불편합니다. grim은 두 방식의 장점을 결합합니다.

---

## 에디터 화면 구성

```
┌─────────────────────┬─────────────────────┐
│  [Format]           │ [−] 100% [+] [Reset] [Fit] │
│                     │                     │
│   코드 에디터        │   SVG 미리보기       │
│   (textarea)        │                     │
│                     │                     │
└─────────────────────┴─────────────────────┘
```

| 영역 | 설명 |
|------|------|
| **좌측 코드 에디터** | `.grim` 문법으로 다이어그램을 코드로 작성합니다. |
| **우측 SVG 미리보기** | 코드 변경 시 300ms 디바운스 후 자동으로 렌더링됩니다. |
| **Format 버튼** | 코드를 정렬하고 들여쓰기를 통일합니다. |
| **줌 컨트롤** | 미리보기 패널의 확대/축소를 제어합니다. |

---

## 기본 워크플로우

1. **코드 작성**: 좌측 에디터에 `.grim` 문법으로 노드와 엣지를 정의합니다.
2. **미리보기 확인**: 입력을 멈추면 우측에 SVG가 자동으로 그려집니다.
3. **마우스로 조정**: 미리보기에서 노드를 드래그하거나 크기를 조절합니다.
4. **코드 자동 반영**: 마우스 조작 결과가 `@layout` 등 메타데이터 주석으로 코드에 삽입됩니다.

---

## 저장 & 공유

- **자동 저장**: 편집 내용이 압축되어 브라우저 URL 프래그먼트(`#z=...`)에 실시간으로 저장됩니다. 탭을 닫아도 URL로 복원할 수 있습니다.
- **공유**: 현재 URL을 그대로 복사해 다른 사람과 공유할 수 있습니다.
- **Short Link**: URL이 너무 길면 **Short Link** 버튼으로 현재 내용을 서버에 저장하고 `/view/{id}` 짧은 링크를 받을 수 있습니다. ([다이어그램 공유](sharing) 참고)
- **읽기 전용 뷰**: `/view#z={압축데이터}` URL로 편집 기능 없이 다이어그램만 볼 수 있습니다.
- **외부 임베딩**: `<grim-viewer>` 커스텀 엘리먼트로 외부 사이트에 다이어그램을 삽입할 수 있습니다.
