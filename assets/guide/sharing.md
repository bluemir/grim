# 다이어그램 공유

grim에서 만든 다이어그램을 다른 사람과 공유하는 방법을 알아봅니다.

## URL 기반 공유 (기본)

grim은 다이어그램 소스 코드를 URL에 Base64로 인코딩하여 저장합니다. 브라우저 주소창의 URL을 그대로 복사하면 누구에게나 공유할 수 있습니다.

- 별도의 서버 저장 없이 URL만으로 다이어그램을 복원할 수 있습니다.
- 다이어그램이 복잡해지면 URL이 길어질 수 있습니다.

## Short Link (서버 저장)

다이어그램을 서버에 저장하고 짧은 URL로 공유할 수 있습니다.

### 사용 방법

1. 에디터에서 다이어그램을 작성합니다.
2. 우측 상단의 **"Short Link"** 버튼을 클릭합니다.
3. 다이어그램이 서버에 저장되고, URL이 `/edit/{id}` 형태로 변경됩니다.
4. 동시에 `/view/{id}` URL이 클립보드에 복사됩니다.
5. 이후 편집하면 자동으로 서버에 저장됩니다.

### Short Link URL 형식

- **편집**: `/edit/{id}` — 에디터에서 다이어그램을 편집할 수 있습니다.
- **보기**: `/view/{id}` — 읽기 전용으로 다이어그램을 볼 수 있습니다.

### 서버 설정

Short Link 기능은 기본적으로 비활성화되어 있습니다. 서버 설정 파일에서 활성화할 수 있습니다.

```hjson
{
    backend: {
        storage: {
            enabled: true
        }
    }
}
```

설정 파일 경로는 서버 실행 시 `-c` 또는 `--config` 옵션으로 지정합니다.

```bash
grim server -c config.hjson --db-path ./grim.db
```

> **참고**: Short Link 기능을 사용하려면 `--db-path` 옵션으로 영구 데이터베이스 경로를 지정해야 합니다. 기본값인 `:memory:`는 서버 재시작 시 데이터가 사라집니다.
