# 핵심 개념

## 양방향 동기화

grim의 핵심 철학은 **코드와 GUI가 항상 일치**한다는 것입니다.

마우스로 노드를 이동하거나 크기를 조절하면, 그 결과가 코드의 `@layout` 주석으로 자동 삽입됩니다. 반대로 코드를 수정하면 미리보기가 즉시 업데이트됩니다.

```grim
# 마우스로 노드를 옮기면 아래와 같이 코드가 자동으로 변경됩니다:
@layout {x: 100, y: 150}
server
```

GUI 조작이 코드를 "훼손"하지 않습니다. 메타데이터 지시자는 노드 선언 바로 위에 삽입되며, 기존 코드 구조는 유지됩니다.

---

## 고정 노드 vs 미고정 노드

grim은 두 가지 레이아웃 모드를 혼합하여 사용합니다.

### 고정 노드 (`@layout` 있음)

`@layout` 지시자가 있는 노드는 지정된 좌표에 **정확히 배치**됩니다. 사용자가 의도적으로 위치를 정한 노드입니다.

```grim
@layout {x: 200, y: 100}
my-node
```

중첩 노드의 경우, 부모 노드의 좌측 상단 `(0, 0)`을 기준으로 하는 **상대 좌표**를 사용합니다.

### 미고정 노드 (`@layout` 없음)

`@layout`이 없는 노드는 **12열 그리드**에 자동으로 배치됩니다.

- 코드 선언 순서대로 왼쪽→오른쪽, 위→아래로 배치됩니다.
- 텍스트 길이와 shape 종류에 따라 1~12열을 차지합니다.
- 고정 노드가 있는 영역과 겹치지 않도록 분리된 공간에 배치됩니다.

---

## 메타데이터 지시자 개요

| 지시자 | 역할 |
|--------|------|
| `@layout` | 노드의 위치(x, y)와 크기(w, h) |
| `@style` | 채우기 색상, 테두리, 글자 크기 등 시각 속성 |
| `@shape` | 노드의 모양 (사각형, 원, 다이아몬드 등) |
| `@text` | 노드에 표시할 텍스트 (plain, markdown, latex 지원) |
| `@edge` | 엣지의 라우팅 (anchor, waypoint, gap) |
| `@icon` | 노드에 표시할 아이콘 이미지 URL |

자세한 내용은 [메타데이터 지시자](syntax/metadata)를 참고하세요.

---

## 암시적 노드 선언

엣지(`A -> B`)에 등장하는 노드는 따로 선언하지 않아도 자동으로 인식됩니다.

```grim
# A와 B를 별도로 선언하지 않아도 동작합니다
A -> B
```

마우스로 암시적 노드를 이동하면, grim이 해당 노드를 자동으로 명시적 선언으로 변환하고 `@layout`을 추가합니다.
